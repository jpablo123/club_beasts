# Stack Tecnológico - Club Beasts David Rozo

## Frontend
- **Framework**: Next.js 15 (App Router)
- **UI**: React + TypeScript + Tailwind CSS
- **Auth**: NextAuth v5 (Auth.js)
- **Testing**: Vitest (unit/integration) + Playwright (e2e) + vitest-cucumber (ATDD)

## Backend
- **Runtime**: Node.js
- **Framework**: Fastify + TypeScript
- **ORM**: Prisma
- **DB**: PostgreSQL
- **Testing**: Vitest + fastify.inject

## Infraestructura
- **Frontend**: Vercel
- **Backend**: Railway
- **DB**: Supabase o Neon (PostgreSQL managed)

## Convenciones
- **Branching**: Trunk-based (feature branches → main)
- **Gestión**: Archivos .md (SPRINTS.md + .feature Gherkin)
- **Commit**: Conventional Commits (feat:, fix:, chore:)
- **Linting**: ESLint + Prettier
- **Node**: v20+ LTS
